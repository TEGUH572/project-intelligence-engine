# Contributing to Project Intelligence Engine

First of all, thank you for considering contributing to Project Intelligence Engine! 🎉

We welcome contributions of all kinds, including:

- Bug fixes
- New features
- Documentation improvements
- Performance optimizations
- Code refactoring
- Test coverage improvements

---

# Getting Started

## 1. Fork the Repository

Click the **Fork** button on GitHub.

## 2. Clone Your Fork

```bash
git clone https://github.com/<your-username>/project-intelligence-engine.git
cd project-intelligence-engine
```

## 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate it:

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

## 4. Install Dependencies

```bash
python -m pip install -r requirements.txt
```

---

# Development Workflow

Create a new branch before making changes.

```bash
git checkout -b feature/your-feature-name
```

Examples:

```text
feature/add-solana-support
feature/improve-scoring
fix/github-parser
docs/update-readme
```

---

# Code Style

Please follow these guidelines:

- Use Python 3.11+
- Follow PEP 8
- Write descriptive function names
- Keep functions focused on a single responsibility
- Add comments only where necessary

---

# Testing

Before submitting a Pull Request, ensure that:

- The project runs successfully
- Existing functionality is not broken
- New features are tested

---

# Commit Messages

Use meaningful commit messages.

Good examples:

```text
Add repository ranking system

Improve GitHub parser

Fix scoring calculation bug

Update README documentation
```

Avoid messages like:

```text
Update

Fix

Test

asdf
```

---

# Pull Requests

Before opening a Pull Request:

- Ensure your branch is up to date.
- Resolve merge conflicts.
- Update documentation if needed.
- Keep Pull Requests focused on a single feature.

---

# Reporting Bugs

Please include:

- Operating System
- Python Version
- Error Message
- Steps to Reproduce
- Expected Behavior

---

# Feature Requests

Feature requests are welcome.

Please explain:

- What problem it solves
- Why it is useful
- Example use case
