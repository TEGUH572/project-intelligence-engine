# Contributor Covenant Code of Conduct

## Our Pledge

We as members, contributors, and maintainers pledge to make participation in our community a respectful, welcoming, and harassment-free experience for everyone, regardless of:

- Age
- Body size
- Disability
- Ethnicity
- Gender identity and expression
- Level of experience
- Nationality
- Personal appearance
- Race
- Religion
- Sexual identity and orientation

We are committed to creating an open, inclusive, and positive environment.

---

## Our Standards

Examples of behavior that contributes to a positive environment include:

- Being respectful and welcoming.
- Using inclusive language.
- Accepting constructive criticism gracefully.
- Focusing on what is best for the community.
- Showing empathy toward other contributors.
- Helping newcomers learn and grow.

Examples of unacceptable behavior include:

- Harassment or discrimination.
- Offensive comments or personal attacks.
- Trolling or insulting others.
- Publishing private information without permission.
- Any form of intimidation or threatening behavior.
- Spam or intentionally disruptive actions.

---

## Our Responsibilities

Project maintainers are responsible for:

- Clarifying and enforcing this Code of Conduct.
- Taking appropriate and fair corrective action.
- Removing inappropriate content when necessary.
- Maintaining a welcoming environment.

---

## Scope

This Code of Conduct applies within all project spaces, including:

- GitHub Issues
- Pull Requests
- Discussions
- Community forums
- Project documentation
- Any public representation of the project

---

## Enforcement

If you experience or witness unacceptable behavior, please report it to the project maintainers through GitHub Issues or Discussions.

All reports will be reviewed promptly and handled fairly.
