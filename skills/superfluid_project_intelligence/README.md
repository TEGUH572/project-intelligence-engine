# 🚀 Superfluid Project Intelligence

> AI-powered Project Intelligence Engine for researching, evaluating, and preparing Web3 projects for Superfluid integration.

Superfluid Project Intelligence automates the discovery and analysis of blockchain projects by combining website research, GitHub intelligence, protocol knowledge, SDK detection, and integration guidance into a single workflow.

---

# ✨ Key Features

## 🌐 Website Intelligence

- Official website discovery
- Metadata extraction
- Social links detection
- Documentation discovery

---

## 🏆 GitHub Intelligence

- Organization discovery
- Repository ranking
- Repository health analysis
- Contributors analysis
- Releases analysis
- Pull Request activity
- Officiality verification

---

## 🧠 Knowledge Intelligence

- Funding information
- Investors
- Supported networks
- Ecosystem support
- Streaming capability
- Protocol use cases

---

## 📦 SDK Intelligence

Automatically detects:

- SDK availability
- Programming languages

- Official documentation
- SDK packages

# 🚀 Quick Start

Clone the repository:

```bash
git clone https://github.com/<your-account>/Airdrop-Research-Assistant.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python demo.py
```
